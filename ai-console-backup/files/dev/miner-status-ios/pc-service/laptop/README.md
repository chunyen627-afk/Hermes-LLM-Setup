## 保護（兩層）

筆電保護程式：
- 記憶體鎖 6001 MHz；核心上限從 800 MHz 起（600–900）
- 74°C 起每 15 秒降 50 MHz；連續 3 分鐘 ≤70°C 才升 50 MHz
- 實際時脈高於上限（被外部改掉）就立刻重設——測試時曾因手動改時脈讓保護失效，已補上
- 80°C 停止挖礦；88°C、或停止後 1 分鐘仍 ≥85°C → 60 秒後關機
- 改用電池（拔電源）立即停止；開始時在電池上就拒絕啟動
- 讀不到溫度 3 次、log 3 分鐘沒更新 → 停止
- 45 分鐘沒有被接受的份額 → 重啟礦工一次；重啟後又 45 分鐘沒有（累計 90 分鐘）→ 停止。筆電平均約 7 分鐘一個份額（中位 5 分鐘），10/26 一晚出現兩次 24 分鐘空窗，舊的「30 分鐘停止」每天會誤停 2–3 次；90 分鐘純屬運氣的機率約百萬分之二。重啟→停止流程已用 30 秒版本實測
- 主控台選取模式（QuickEdit）在啟動時關閉
- 礦工在 Job Object 裡，保護程式結束時礦工一起結束
- 挖礦時 CPU 最高效能 80%；停止時還原時脈、記憶體與 CPU 設定

office 彙整服務（`aggregator.json` 的 `laptop.guardian`）：
- 礦工在跑且 ≥82°C → 遠端建立 STOP 並強制結束 krig，ntfy 緊急通知
- 礦工在跑但狀態超過 90 秒沒更新（保護程式當掉）→ 同上
- ≥90°C → 遠端關機（30 秒）
- 同一事件只處理一次；恢復正常後才會再處理
