# Swift 調校與 Hermes 桌面驗收 — 2026-10-19

## 採用結論

目前使用 **Swift 1.5 Qwen3.8 Flash Next Abliterated IQ3_XXS**，模型 ID 為 `swift-1.5-qwen3.8-flash-next-abliterated-iq3_xxs`。
本輪沒有更換模型權重或量化，而是調整 Strata 引擎、GPU 順序／分層及 CUDA 選項。

「模型＋靜態生圖」已套用新設定，保留 **262144 tokens（256K）** 上下文。約 16K 內容下，同一 Swift 模型的生成速度從 **31.7165 → 51.915 TPS，提升 63.7%（約 1.64 倍）**。
Hermes 桌面抽測約 **40～45 TPS**，本輪功能驗收完成，使用者接下來實際使用觀察；**尚未認定長期穩定**。

這不是 Swift 與原非 Swift 模型的直接對照，不能把增益全歸因於換模型，也不能推論填滿 256K 仍有 52 TPS。
影片模式沿用調校前配置，本輪沒有重新生成完整靜態圖片或影片。

## 測量方法與對照

固定相同模型與提示詞、temperature 0、seed 214；基準關閉思考以分離生成速度。
短題為英文程式、說明文、繁體中文程式三種，每題最多生成 256 tokens，暖機後兩輪。
長題含同一份程式背景，共 15834 prompt tokens，每輪生成 512 tokens；第二輪重用背景。
TPS 為輸出 token 數除以 decode 秒數，不包含輸入讀取、工具執行，也不是瞬間峰值。

| 配置 | 短題各輪中位數 TPS | 16K 兩輪 TPS |
|---|---|---|
| 0.1.40、原 GPU 順序 | 30.227 / 30.066 | 33.210 / 30.223 |
| 0.1.45、原 GPU 順序 | 31.000 / 29.368 | 32.854 / 29.023 |
| 0.1.45、新 GPU 順序 | 45.675 / 49.296 | 48.310 / 47.970 |
| 新順序＋五個 CUDA 選項（採用） | 45.843 / 49.051 | 51.713 / 52.117 |

主要改善來自 GPU 順序／分層；僅升級引擎沒有顯示一致提升。
首次讀取 16K 背景從 93.651 秒降至 68.120 秒（約減少 27.3%）；重用相同背景時約 0.1 秒，不能當作首次讀取速度。

其他已比較但未採用的調整：

- PCIe 比例 0 / 0.2 / 0.35 / 0.55 / 0.75；MTP 門檻 0.3 / 0.5 / 0.7 / 0.9。
- PCIe 0.55、MTP 門檻 0.5 候選在三輪交錯測試的增益中位數約 3.56%，小於本輪保守採用門檻 5%，保留 0 / 0.7。
- CPU workers 9 / 6 / 4 的兩輪中位數均值約 31.84 / 31.49 / 30.34 TPS，保留 9。
- `STRATA_EXCHANGE_ROTATE` 因本機缺少 fully mapped/pinned RAM complement 而未生效，正式設定不包含該選項。

## 正確性與實際桌面驗收

23 份包含完整 `lower_bound` 函式的輸出，各通過 103 個獨立邊界／固定種子隨機案例。
另 27 份輸出因測速 token 上限造成程式碼區塊不完整，未列為通過；不把測速完成等同任務正確。

Hermes 桌面實際使用圖片附件、聊天輸入框與 terminal 工具：

| 驗收 | 結果 | 生成 TPS |
|---|---|---|
| Low：原生看圖＋程式 | 正確辨識 R7-K2、左紅色正方形、右藍色圓形，產生 lower_bound | 41.8 |
| Low：實際工具與回報 | 空陣列、重複值、超過最大值三項 assert 通過；展開工具卡核對 exit code 0、`ALL PASS: 0 1 3` | 45.1 |
| High：條件機率題 | 從桌面設定選高，新建對話；正確回答 2/11，顯示「已思考」，正常完成 | 40.3 |

Low 第一輪 19316 prompt / 1112 output，讀取輸入 78.29 秒、生成 26.58 秒。
工具後一輪 19568 prompt（重用 19311）/ 314 output，讀取 3.26 秒、生成 6.96 秒。
High 為 19010 prompt（重用 18939）/ 358 output，讀取 2.50 秒、生成 8.87 秒。
這是功能與相容性抽測，沒有驗證各推理強度的品質差異；測後預設恢復 **Low**。

長的新對話仍可能先等待輸入處理；此數據不保證所有題目、完整 256K 或生圖同時運行時都有相同速度。
